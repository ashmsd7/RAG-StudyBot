# RAG StudyBot

A Retrieval-Augmented Generation (RAG) study assistant built using Python, vector databases, and LLMs.

## Features
- Document ingestion
- Semantic search
- Question answering
- Adaptive study support

## Tech Stack
- Python
- ChromaDB
- LLM APIs
- Frontend + Backend architecture

## Setup
1. Clone repository
2. Install requirements
3. Configure .env
4. Run start.bat
